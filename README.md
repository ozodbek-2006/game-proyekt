# GAME PROYEKT

GAME EVENT demo sayti: o’yin zonalari, bron, arenda, do’kon va CS skinlar uchun interfeys.

## Ishga tushirish

`index.html` faylini brauzerda oching. Steam’dagi CS2, Dota 2 va PUBG muqova rasmlari internet orqali yuklanadi.

## Eslatma

Bu front-end demo. Ma’lumotlar brauzer xotirasida saqlanadi; haqiqiy server, xavfsiz admin tizimi yoki real to’lov integratsiyasi yo’q. Haqiqiy mijoz ma’lumotlari yoki to’lov ma’lumotlarini kiritmang.
